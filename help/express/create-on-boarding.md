# Crie conteúdo de recrutamento e de integração com o Firefly

Saiba mais sobre como usar o recurso Texto para imagem, habilitado por Adobe Firefly, em Adobe Express para criar gráficos exclusivos para o recrutamento de funcionários e conteúdo de integração. Neste exemplo, os modelos são usados para que todos na empresa criem conteúdo precisamente sob a marca. Este tutorial usa o novo [Adobe Express](https://www.adobe.com/br/express/).
