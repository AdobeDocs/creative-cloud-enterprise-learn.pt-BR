# Mover arte vetorial para um layout de InDesign e empacotá-lo para entrega

Arquivos prontos para impressão significam muito para controlar: links, sangrias, fontes e texto com excesso de tipos. Saiba como verificar se há sangria, texto com excesso de tipos e fontes ou links ausentes no layout de impressão e obter correções perguntando ao Assistente de IA em InDesign. Em seguida, verifique na Comprovação e empacote tudo para entrega.
